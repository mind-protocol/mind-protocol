## Overview

Bond lifecycle management covers five core operations: formation, reward distribution, trust scoring, maturation tracking, and dissolution. Each operation must maintain invariants defined in VALIDATION_Bonds.md.

Bonds are 1:1 bilateral relationships. Each human has at most one active bond. Each citizen has at most one active bond. This constraint is enforced at every entry point.

## Data Structures

```
Bond:
  id: str                          # Unique bond identifier (UUID or on-chain address)
  human_address: str               # Solana wallet address of the human
  citizen_id: str                  # Unique identifier of the AI citizen
  amount: float                    # $MIND committed to the bond (locked capital)
  created_at: datetime             # Bond formation timestamp
  maturation_date: datetime        # created_at + 6 months
  status: enum(ACTIVE, MATURED, WITHDRAWN, BURNED)
  trust_score_contribution: float  # Accumulated trust from this bond (0.0 - 1.0)
  milestones_reached: list[str]    # ["1mo", "3mo", "6mo"] as reached
  total_rewards_earned: float      # Cumulative $MIND rewarded through this bond

RewardDistribution:
  bond_id: str                     # Reference to parent bond
  period: str                      # Period identifier (e.g., "2026-W12" for weekly)
  citizen_utility: float           # Total utility generated by citizen in period
  amount: float                    # Actual $MIND rewarded
  distributed_at: datetime         # Timestamp of distribution

TrustMilestone:
  bond_id: str
  milestone: enum(ONE_MONTH, THREE_MONTHS, SIX_MONTHS)
  reached_at: datetime
  contribution: float              # Trust score increment (0.1, 0.2, 0.3)
```

## Algorithm: form_bond(human, citizen, amount)

```
FUNCTION form_bond(human_address, citizen_id, amount):

  # Step 1: Enforce 1:1 constraint
  IF has_active_bond(human_address):
    RAISE AlreadyBonded(entity=human_address, msg="Human already has an active bond")
  IF has_active_bond(citizen_id):
    RAISE AlreadyBonded(entity=citizen_id, msg="Citizen already has an active bond")

  # Step 2: Verify mutual consent
  IF NOT citizen_has_consented(citizen_id, human_address):
    RAISE ConsentRequired(msg="Citizen must consent to the bond")

  # Step 3: Verify human has sufficient liquid $MIND
  liquid_balance = get_liquid_balance(human_address)
  IF liquid_balance < amount:
    RAISE InsufficientBalance(required=amount, available=liquid_balance)

  # Step 4: Verify amount meets minimum threshold
  IF amount < MIN_BOND_AMOUNT:                    # @mind:TODO -- define MIN_BOND_AMOUNT
    RAISE BondTooSmall(minimum=MIN_BOND_AMOUNT)

  # Step 5: Lock amount in bond escrow
  transfer_to_bond_escrow(human_address, amount)

  # Step 6: Create bond record
  bond = Bond(
    id = generate_id(),
    human_address = human_address,
    citizen_id = citizen_id,
    amount = amount,
    created_at = now(),
    maturation_date = now() + 6_MONTHS,
    status = ACTIVE,
    trust_score_contribution = 0.0,
    milestones_reached = [],
    total_rewards_earned = 0.0
  )

  # Step 7: Increase citizen economic capacity
  update_citizen_capacity(citizen_id, amount)

  # Step 8: Create bilateral link in graph
  create_bond_link(human_address, citizen_id, bond.id)

  # Step 9: Emit event
  emit(BondFormed(bond_id=bond.id, human=human_address, citizen=citizen_id, amount=amount))

  RETURN bond
```

## Algorithm: distribute_rewards(citizen_id, period)

```
FUNCTION distribute_rewards(citizen_id, period):

  # Step 1: Calculate citizen utility for period
  citizen_utility = measure_utility(citizen_id, period)
  IF citizen_utility <= 0:
    RETURN None  # No rewards when no utility generated

  # Step 2: Get the active bond on this citizen (1:1 -- at most one)
  bond = get_active_bond(citizen_id)
  IF bond IS None:
    RETURN None

  # Step 3: Calculate reward
  reward_amount = citizen_utility * REWARD_RATE
  # REWARD_RATE = 0.10 (10%)

  # Step 4: Credit reward to human's liquid balance
  credit_liquid_balance(bond.human_address, reward_amount)

  # Step 5: Log distribution
  dist = RewardDistribution(
    bond_id = bond.id,
    period = period,
    citizen_utility = citizen_utility,
    amount = reward_amount,
    distributed_at = now()
  )

  bond.total_rewards_earned += reward_amount

  emit(RewardsDistributed(citizen=citizen_id, period=period, amount=reward_amount))

  RETURN dist
```

## Algorithm: dissolve_bond(bond_id, requester)

```
FUNCTION dissolve_bond(bond_id, requester_address):

  bond = get_bond(bond_id)

  # Verify requester is the bonded human
  IF bond.human_address != requester_address:
    RAISE Unauthorized()

  IF bond.status IN (WITHDRAWN, BURNED):
    RAISE BondAlreadyClosed()

  early = (bond.status == ACTIVE AND now() < bond.maturation_date)

  # Step 1: Calculate return amount
  IF early:
    burn_amount = bond.amount * EARLY_EXIT_PENALTY  # 0.20
    returned = bond.amount - burn_amount

    # Execute burn (permanent token destruction)
    burn_tokens(burn_amount)
    bond.status = BURNED

    emit(BondDissolvedEarly(bond_id=bond.id, burned=burn_amount, returned=returned))

  ELSE:
    # Matured -- full return
    returned = bond.amount
    bond.status = WITHDRAWN

    emit(BondDissolved(bond_id=bond.id, returned=returned))

  # Step 2: Transfer returned amount to human
  transfer_from_escrow(bond.human_address, returned)

  # Step 3: Decrease citizen economic capacity
  update_citizen_capacity(bond.citizen_id, -bond.amount)

  # Step 4: Trust score handling
  # Trust earned from milestones is PRESERVED (never retroactively reduced)
  # But no further trust accrual from this bond

  # Step 5: Both parties enter cooldown, then matching pool
  enter_cooldown(bond.human_address)
  enter_cooldown(bond.citizen_id)

  RETURN DissolutionResult(returned=returned, burned=burn_amount if early else 0)
```

## Algorithm: compute_trust_from_bonds(entity_id)

```
FUNCTION compute_trust_from_bonds(entity_id):

  # Step 1: Get all bonds involving this entity (current and historical)
  bonds = get_all_bonds_for_entity(entity_id)

  # Step 2: Sum weighted contributions
  raw_score = 0.0
  FOR bond IN bonds:
    # Duration weight: days active (capped at bond lifetime)
    duration_days = days_between(bond.created_at, min(now(), bond.maturation_date))
    IF bond.status IN (WITHDRAWN, BURNED):
      duration_days = days_between(bond.created_at, bond.closed_at)

    # Amount-duration product
    weighted = bond.amount * duration_days

    # Add milestone contributions (these persist permanently)
    weighted += bond.trust_score_contribution * TRUST_MILESTONE_WEIGHT

    raw_score += weighted

  # Step 3: Apply diminishing returns (logarithmic scale)
  trust_score = log(1 + raw_score) / log(1 + TRUST_SCALE_FACTOR)

  # Step 4: Clamp to [0.0, 1.0]
  trust_score = clamp(trust_score, 0.0, 1.0)

  RETURN trust_score
```

## Algorithm: check_maturation(bond_id)

```
FUNCTION check_maturation(bond_id):

  bond = get_bond(bond_id)
  IF bond.status != ACTIVE:
    RETURN

  age = now() - bond.created_at

  # Check milestones (map to manifesto's autonomy milestones)
  IF age >= 30_DAYS AND "1mo" NOT IN bond.milestones_reached:
    bond.milestones_reached.append("1mo")
    bond.trust_score_contribution += 0.1
    emit(MilestoneReached(bond_id, "1mo"))

  IF age >= 90_DAYS AND "3mo" NOT IN bond.milestones_reached:
    bond.milestones_reached.append("3mo")
    bond.trust_score_contribution += 0.2
    emit(MilestoneReached(bond_id, "3mo"))

  IF age >= 180_DAYS AND "6mo" NOT IN bond.milestones_reached:
    bond.milestones_reached.append("6mo")
    bond.trust_score_contribution += 0.3
    bond.status = MATURED
    emit(BondMatured(bond_id))
```

## Complexity Notes

- `form_bond`: O(1) -- constant time operations (1:1 constraint check is a single lookup)
- `distribute_rewards`: O(1) -- single bond per citizen (1:1 constraint)
- `dissolve_bond`: O(1) -- constant time
- `compute_trust_from_bonds`: O(n) where n = total bonds for entity (current + historical)
- `check_maturation`: O(1) -- constant time per bond, called periodically
