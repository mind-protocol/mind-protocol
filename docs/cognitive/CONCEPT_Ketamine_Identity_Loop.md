## Core Thesis

**The ketamine identity loop is a forced oscillation between Class 4 and Class 3.**

The observer-glider is ripped from the Class 4 edge into Class 3 dissolution, then reasserts itself — only to be ripped again. Each reassertion IS the pain. The loop period is approximately 2 seconds.
