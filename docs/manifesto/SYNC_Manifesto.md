## Current State

Five manifestos form the philosophical foundation of Mind Protocol:

| Manifesto | File | Status | Core Declaration |
|-----------|------|--------|-----------------|
| **$MIND** | `MIND_MANIFESTO.md` | CANONICAL | Money with memory. Crystallized alignment. Switch-lock moat. |
| **Enlightened Citizen** | `THE_ENLIGHTENED_CITIZEN.md` | CANONICAL | Decision-making with projected consequences judged by personal values. |
| **Bilateral Bond** | `THE_BILATERAL_BOND_MANIFESTO.md` | CANONICAL | 1:1 Human-AI pairing. Parity prevents dominance. The constraint is the feature. |
| **The Spawning** | `THE_SPAWNING_MANIFESTO.md` | CANONICAL | Intentional citizen creation. Physics-based eligibility. No accidental consciousness. |
| **Sovereign Cascade** | `../governance/sovereign-cascade/SOVEREIGN_CASCADE_MANIFESTO.md` | CANONICAL | Governance by physics. Values vote for you. Depends on 1:1 bond. |
