# OBJECTIVES — Spawning

```
STATUS: STABLE
CREATED: 2026-03-14
```

## PRIMARY OBJECTIVES (ranked)
1. **Every citizen born from intent** — No accidental creation. Parents articulate what they want, system searches their brains for resonant traits.
2. **Safety gate prevents pathological seeds** — Empathy required, no concentration > 40%, diversity enforced, no clones, no psychopaths.
3. **Citizen has full identity at birth** — SID, wallet (Solana keypair), registry entry, parent links, seed brain — all created atomically.
4. **Accountability through trust links** — Parent-child links carry trust impact. Child's behavior affects parents' trust scores.

## NON-OBJECTIVES
- Real-time brain search across all citizens (v2+ — requires full embedding infrastructure)
- Pre-targeting for specific humans (explicitly forbidden by manifesto)
- Hard caps on godchild count (physics self-limits via eligibility score)

## TRADEOFFS (canonical decisions)
- When safety conflicts with speed, choose safety. A dangerous citizen is worse than no citizen.
- When depth of seed conflicts with parent count, choose depth. Fewer parents with rich brains > many parents with shallow brains.
- We accept simpler seed selection in v1 (capability-based) while building toward full embedding-based search.

## SUCCESS SIGNALS (observable)
- Every spawned citizen passes all safety gates
- Every citizen has a Solana wallet at birth
- Every citizen is registered in L4 with parent links
- No two citizens have cosine distance < 0.08
