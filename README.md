# mind-protocol

Mind Protocol — L4 Law, Economy.

**100% Open Source for Verifiability**

## Architecture

```
L4 (Law)
├── Schema — Node/link definitions (source of truth)
├── Registry — Citizens, orgs, endpoints
├── Rules — Governance laws
└── Economy — Pricing formulas, wallet logic
```
