## Core Thesis

**Tension is the engine.**

SubEntities spawn from tension (need + absence). Exploration is driven by tension. Crystallization resolves tension.

Without tension, nothing moves. With too much tension, everything fragments. Optimal tension is where growth happens.

```
tension = need × (1 - satisfaction)
```

## The Mechanics

### When Tension Is Zero

```yaml
zero_tension:
  condition: need = 0 OR satisfaction = 1

  effect:
    - no exploration happens
    - no crystallization happens
    - system is static
    - entropy increases (decay)

  human_equivalent:
    - boredom
    - stagnation
    - "nothing matters"
    - depression (in one form)

  build_equivalent:
    - no bugs, no features
    - maintenance mode
    - slowly rotting
```

### When Tension Is High

```yaml
high_tension:
  condition: need is high AND satisfaction is low

  effect:
    - exploration intensifies
    - branching increases
    - crystallization threshold drops
    - new structures form rapidly

  human_equivalent:
    - anxiety
    - urgency
    - creative pressure
    - breakthrough or breakdown

  build_equivalent:
    - critical failures
    - deadline pressure
    - rapid development
    - innovation or collapse
```

### When Tension Is Optimal

```yaml
optimal_tension:
  condition: meaningful need, partial satisfaction

  effect:
    - productive exploration
    - sustainable crystallization
    - growth without fragmentation
    - flow state possible

  human_equivalent:
    - engaged challenge
    - meaningful work
    - flow
    - productive anxiety (eustress)

  build_equivalent:
    - important problems to solve
    - resources to solve them
    - progress visible
```

```yaml
attention_allocation:
  mechanism: |
```

```yaml
meaning_creation:
```

## Managing Tension

### Creating Appropriate Tension

```yaml
creating_tension:
  methods:
    - present meaningful problems
    - set real stakes
    - make gaps visible
    - introduce productive conflict

  dangers:
    - artificial tension (feels manufactured)
    - too much tension (overwhelm)
    - sadistic tension (suffering for its own sake)

  balance: |
    Tension should be:
    - Real (not manufactured)
    - Meaningful (connected to actual needs)
    - Resolvable (with sufficient effort)
    - Bounded (not infinite)
```

### Sustaining Tension

```yaml
sustaining_tension:
  methods:
    - delay premature resolution
    - introduce complications
    - raise stakes appropriately
    - maintain engagement

  dangers:
    - frustration from unresolvable tension
    - fatigue from sustained pressure
    - abandonment when hope fades

  balance: |
    Tension should be:
    - Sustaining (keeps engagement)
    - Progressable (steps toward resolution visible)
    - Bounded (end condition exists)
```

### Resolving Tension

```yaml
resolving_tension:
  methods:
    - crystallization (create new structure)
    - absorption (integrate existing knowledge)
    - meaning-making (interpret the journey)
    - acceptance (when resolution impossible)

  dangers:
    - premature resolution (shallow crystallization)
    - false resolution (unaddressed root)
    - over-resolution (killing productive tension)

  balance: |
    Resolution should be:
    - Earned (proportional to tension)
    - Complete (addresses the need)
    - Generative (creates new capacity)
```
