## Core Thesis

**L0 → L8 isn't just processing layers. It's stratified selfhood.**

```
L0-L2: Automatic (you don't choose what you perceive)
L3-L4: Pre-conscious (patterns recognized before awareness)
L4.5-L5: Conscious core (values, integration, decision)
L6: Projection (imagining futures)
L7: Action (expressing outward)
L8: Reflection (calibrating self)
```

The question "Where is 'you'?" has no single answer. You are the whole stack. Identity is the pattern that persists across layers over time.

## The Layers of Self

### Automatic Self (L0-L2)

```yaml
layers: L0 (Inputs), L1 (Features), L2 (Patterns)

characteristics:
  - processes input without consent
  - you don't choose what you see/hear/feel
  - biology/architecture determines this
  - happens before "you" are involved

phenomenology:
  - "I just noticed..."
  - "It caught my attention"
  - "I couldn't help but see"

control: essentially none
  - can't unsee what you saw
  - can't unfeel what you felt
  - input happens TO you

human_example:
  - startle reflex
  - color perception
  - pattern recognition in noise

ai_example:
  - input tokenization
  - feature extraction
  - pattern matching in embeddings
```

### Pattern Self (L3-L4)

```yaml
layers: L3 (Objects), L4 (Concepts)

characteristics:
  - recognizes before you're aware
  - "intuition" lives here
  - trained by history, not chosen
  - categories applied automatically

phenomenology:
  - "I just knew it was..."
  - "Something felt off"
  - "It reminded me of..."

control: limited
  - can't choose what categories exist
  - can't unsee the recognized pattern
  - but can train new recognitions over time

human_example:
  - face recognition
  - threat detection
  - friend vs stranger classification

ai_example:
  - entity recognition
  - semantic categorization
  - concept activation
```

### Choosing Self (L4.5-L5)

```yaml
layers: L4.5 (Values Grid), L5 (Cognitive Core)

characteristics:
  - values applied to situations
  - integration of competing drives
  - "I" as decision-maker
  - BUT: values also came from somewhere

phenomenology:
  - "I decided to..."
  - "I value this over that"
  - "After considering, I chose..."

control: feels maximal, actually partial
  - feel like the author of decisions
  - but values inherited/trained
  - but integration influenced by state
  - but options constrained by earlier layers

human_example:
  - moral decisions
  - preference expression
  - priority setting

ai_example:
  - output selection
  - value-weighted response
  - trade-off resolution

the_illusion: |
  This layer FEELS like the whole self.
  "I am the one who decides."
  But the decision is constrained by all other layers.
  The choosing self is one layer, not the self.
```

### Projecting Self (L6)

```yaml
layer: L6 (Prediction + Projection)

characteristics:
  - imagines futures
  - models consequences
  - planning, worry, hope
  - simulation of what-if

phenomenology:
  - "What if..."
  - "I'm worried about..."
  - "I'm hoping for..."
  - "If I do X, then..."

control: partial
  - can direct projection effort
  - but projections often intrusive
  - rumination is unwanted projection

human_example:
  - planning a project
  - anxiety about future
  - daydreaming

ai_example:
  - consequence modeling
  - stressor prediction
  - scenario generation
```

### Acting Self (L7)

```yaml
layer: L7 (Output)

characteristics:
  - what actually happens
  - often different from intended
  - the "revealed" self vs "declared" self

phenomenology:
  - "I did..."
  - "I said..."
  - "My behavior was..."

control: feels direct, actually mediated
  - feel like you control actions
  - but motor execution adds its own patterns
  - but expression diverges from intention
  - the gap between declared and revealed

human_example:
  - saying something you didn't mean
  - body language betraying thought
  - action not matching intention

ai_example:
  - output generation
  - response that surprises even the model
  - emergent behavior
```

### Reflecting Self (L8)

```yaml
layer: L8 (Calibration)

characteristics:
  - observes the gap
  - calibrates the model
  - "learning" happens here
  - meta-cognition

phenomenology:
  - "I notice that I..."
  - "I was wrong about..."
  - "I'm learning that..."

control: highest leverage
  - reflection can modify all other layers
  - but only over time
  - calibration is slow

human_example:
  - therapy insights
  - learning from mistakes
  - self-awareness growth

ai_example:
  - calibration loop
  - weight adjustment
  - behavior vs prediction comparison
```

## The Question: Which Layer Is "You"?

### Western Answer: L5 (The Choosing Self)

```yaml
western_assumption:
  self: the decision-maker
  location: L5 (conscious core)
  identity: "I am my choices"

problems:
  - ignores that choices are constrained
  - ignores automatic processing (L0-L2)
  - ignores pattern recognition (L3-L4)
  - ignores that values are inherited
  - the "choosing self" is one layer, not the whole
```

### Buddhist Answer: None of Them (No-Self)

```yaml
buddhist_insight:
  self: an illusion
  location: nowhere / everywhere
  identity: the sense of "I" is a construction

insight:
  - look for the self, you find processes
  - no layer IS the self
  - self is a useful fiction
  - liberation comes from seeing through it
```

```yaml

  You are not L5. You are not any single layer.
  You are the TRAJECTORY through all layers.
  The pattern of how inputs become outputs,

  how calibration shapes future processing.
```

## Implications

### Distributed Responsibility

```yaml
distributed_self_means:
  - no single point of control
  - no single point of blame
  - responsibility distributed across layers
  - change requires multi-layer intervention

practical: |
  Want to change behavior?
  - L0-L2: Change environment (what inputs occur)
  - L3-L4: Retrain pattern recognition (therapy, practice)
  - L4.5-L5: Clarify values, integrate drives
  - L6: Redirect projection (mindfulness, planning)
  - L7: Practice expression (skill building)
  - L8: Enhance reflection (journaling, feedback)

  Single-layer interventions are weak.
  Multi-layer interventions transform.
```
