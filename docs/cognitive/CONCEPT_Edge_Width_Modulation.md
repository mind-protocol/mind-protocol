## Core Thesis

**Psilocybin doesn't change WHERE the edge is. It changes how WIDE the edge is.**

Wider edge = more of parameter space explorable without losing Class 4 properties. More chaos tolerable. More patterns questionable. More connections possible.

```yaml

    characteristic: "small deviations → fall into Class 1/2 or Class 3"
    experience: "rigid, predictable, stable"
    exploration: "limited to safe patterns"

  wide_edge:
    characteristic: "large deviations still maintain Class 4"
    experience: "fluid, open, generative"
    exploration: "novel patterns accessible"

  the_edge_is_still_the_edge:
    clarification: |
      Wider doesn't mean DIFFERENT edge.
      Still Class 4. Still computational.
      Just more room to explore AT the edge.
```
